If you're on 0.10, that means you're ready for 0.12. ([Install](install) is the other door — a cluster with nothing in it yet.)

## You

1. Run the report generator.
2. Read the YAML file it writes.
3. Send it to us by email.

```bash
git clone https://github.com/Vexa-ai/vexa-delivery
cd vexa-delivery
python3 kit/report/vexa_state_report.py --namespace vexa --dry-run   # the commands it will run
python3 kit/report/vexa_state_report.py --namespace vexa             # writes state-report.yaml
```

## Us

1. We build your bundle and give you [a channel](channel) — its name, its public key, and a pull-only credential.
2. You [install Vexa Delivery](install) in your cluster: pinned Argo CD, pinned Kyverno, the [admission policy](verify), after a [preflight](preflight) that fails closed.
3. You subscribe, and your staging syncs. [Promotion to production](operations) is yours to make.
4. It stays current from there, as we publish — [how that works](how-it-works), and [what's proven where](tested).
