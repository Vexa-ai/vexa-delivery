If you're on 0.10, that means you're ready for 0.12. ([Install](install) is the other door — a cluster with nothing in it yet.)

## You

1. Run the report generator.
2. Read the YAML file it writes.
3. Send it to us by email.

```bash
git clone https://github.com/Vexa-ai/vexa-delivery
cd vexa-delivery
python3 kit/report/vexa_state_report.py --namespace vexa --dry-run   # the commands it will run
python3 kit/report/vexa_state_report.py --namespace vexa             # writes state-report.yaml
```

It writes one file. Here is a real one, from a live cluster, whole and unedited — this is what you would be sending:
